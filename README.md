## About The Project

Efficiently parallelizing Sparse Matrix-Vector (SpMV) multiplication is a significant challenge due to workload imbalance and irregular memory access patterns.

This repository contains the material for the exam "Introduction to Parallel Computing" (University of Trento). Inside the deliverable folders there are the instructions for reproducibility.
